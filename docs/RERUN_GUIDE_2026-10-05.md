# Re-run Guide (2026-10-05): switch to the reorganized workspace and re-run exp01-exp03

Do the parts in order. Parts A-C take a few minutes; part E takes a few hours (mostly exp01).

## A. Repository (on nicosls)

1. Commit anything pending in the current workspace, then tag the old state and push the tags:

   ```
   git add -A
   git commit -m "state before the reorganization"
   git tag pre-refactor-20261005
   git tag v2-final e482d62
   git push
   git push --tags
   ```
   (`v2-final` was never created in the repository; commit `e482d62` holds the uncorrected v2 outputs. Skip that line if
   `git tag -l` already lists it.)

2. Replace the files: delete everything in the workspace folder **except `.git`** (and a venv folder if there is one),
   then copy the **contents** of the zip's `stock_overflow_workspace/` folder into it. In PowerShell, from the workspace folder:

   ```
   Get-ChildItem -Force | Where-Object { $_.Name -notin @('.git', 'venv-main') } | Remove-Item -Recurse -Force
   Expand-Archive -Path <path to the zip> -DestinationPath $env:TEMP\so_new -Force
   Copy-Item -Path $env:TEMP\so_new\stock_overflow_workspace\* -Destination . -Recurse -Force
   Copy-Item -Path $env:TEMP\so_new\stock_overflow_workspace\.gitignore, $env:TEMP\so_new\stock_overflow_workspace\.cursorignore -Destination . -Force
   ```

3. Commit and push:

   ```
   git add -A
   git commit -m "reorganize the workspace: so/ library, pipeline/, experiments/exp01-exp03, fresh trial log"
   git push
   ```
